# Capas dos projetos

As quatro imagens fornecidas em `public/images` foram convertidas para WebP com orientação automática, largura máxima de 1000 pixels, proporção preservada e qualidade 78.

| Imagem original          | Capa WebP                 | Repositório                           |
| ------------------------ | ------------------------- | ------------------------------------- |
| `Logica python.jpg`      | `logica-python.webp`      | `Logica-Python-1` e `Logica-python-2` |
| `rpg java.jpg`           | `rpg-java.webp`           | `test_rpg_create`                     |
| `sprint Jovi Python.jpg` | `sprint-jovi-python.webp` | `Sprint-Jovi-Python`                  |
| `portfolio-react.png`    | `portfolio-react.webp`    | `portfolio-React`                     |

Os nomes dos repositórios foram consultados pela API pública do GitHub. A imagem genérica de lógica Python é compartilhada entre os dois repositórios de exercícios. As capas são associadas pelo nome em `ProjectCard`; os dados e a listagem continuam vindo da API, com o cache existente. Nenhuma imagem foi enviada aos repositórios remotos.
